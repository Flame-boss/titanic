# 🚢 Titanic Survival Analysis using Python

## 📌 Project Overview

This project explores the famous Titanic dataset to understand the factors that influenced passenger survival. Using Python, I performed exploratory data analysis (EDA), data cleaning, and data visualization to identify patterns and relationships within the data.

The project was developed primarily in **Python** using **PyCharm IDE**, while **Cursor IDE** was used to assist with code writing, debugging, and improving code quality.

This project demonstrates fundamental data analysis skills including data preprocessing, visualization, correlation analysis, and extracting actionable insights from real-world data.

---

# 🎯 Project Objectives

The main objectives of this project were to:

* Explore the Titanic dataset
* Clean and prepare the data for analysis
* Analyze passenger demographics
* Investigate survival rates based on different features
* Create meaningful visualizations
* Practice Python data analysis workflows

# 📂 Dataset

The project uses the **Titanic Training Dataset (train.csv)**.

* Age

* Number of Parents/Children
* Ticket
* Fare
* Cabin
* Embarked
* Survival Status

# 🔎 Data Cleaning

The following preprocessing steps were performed:

* Loaded the dataset using Pandas
* Checked for missing values
* Removed passengers with missing information
* Removed invalid age values
* Filtered ages between 1 and 100 years
* Examined descriptive statistics
* Explored data types

# 📈 Analysis Performed

The project calculates:

* Average survival rate by age
* Average survival rate by passenger class
* Average survival rate by gender

This helps identify which groups had the highest likelihood of survival.

---

# 📌 Key Insights

Some observations from the analysis include:

* Female passengers had a significantly higher survival rate than male passengers.
* First-class passengers were more likely to survive than passengers in lower classes.
* Passenger age influenced survival, with children generally having higher survival rates.
* Passenger class showed one of the strongest relationships with survival.
